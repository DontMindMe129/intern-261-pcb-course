# PCB tham khảo ESP32-P4

Tập hợp từ các file trong Downloads ngày 2026-11-07.

- `ESP32-P4X-EYE/`: PCB V2.3 — bản Allegro `.brd`, PDF từng lớp và PDF Composite.
- `ESP32-P4X-Function-EV-Board/`: PCB V1.6 — bản Allegro `.brd` và PDF layout.
- `ESP32_P4X_C5_Function_EV_board-2.0-pcb-layout.pdf`: PDF layout board P4X-C5 V2.0.
- `archives/`: hai bộ ZIP gốc, gồm cả schematic, BOM, Gerber và tài liệu lắp ráp.

Các schematic đã lưu riêng trong `../schematics/`. Phiên bản PCB ở đây được ghi theo tên file trong ZIP; có thể khác phiên bản schematic đi kèm.

Nguồn file và SHA-256 được lưu trong `sources.json`. Các bản trong Downloads được giữ lại.
